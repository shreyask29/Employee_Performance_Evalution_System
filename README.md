# Employee Performance Evaluation System

## About the Project
A Java desktop application that evaluates employee performance using Communication, Teamwork, and Productivity scores.

## Objectives
- Enter employee details and performance scores.
- Calculate the average score automatically.
- Assign a performance rating based on the average.
- Display employee results in a table.

## Technologies Used
- Java
- Java Swing
- Java AWT
- JTable and DefaultTableModel

## How It Works
1. Enter the employee name.
2. Enter Communication, Teamwork, and Productivity scores from 0 to 10.
3. Click Add Employee.
4. The application calculates the average and displays the rating.

## Average Calculation
Average = (Communication + Teamwork + Productivity) / 3.0

## Rating System
- 8 to 10: Excellent
- 6 to below 8: Good
- 4 to below 6: Average
- Below 4: Needs Improvement

## Features
- Input validation
- Automatic average calculation
- Performance rating
- Table-based results
- Error message for invalid input

## Limitations
- No database or permanent storage
- No login system
- No edit, delete, or search functionality
